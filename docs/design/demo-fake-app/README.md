# Demo fake-app design source

Pencil (.pen) source files for the fake-app shipped at `forkshop.dev/demo`
and reused by `forkshop.dev/studio`. See
[`docs/specs/2026-05-20-marketing-demo-and-studio-design.md`](../../specs/2026-05-20-marketing-demo-and-studio-design.md)
for the design that consumes this.

Drop the `.pen` file in this folder. Read via the pencil MCP — never
with `Read` or `Grep` (the format is encrypted).

Token / primitive / block / page extraction is iterative; each pass is
user-reviewed before the next starts.
