# @forkshop/engine

The Forkshop canvas + sidebar engine for Next.js + Tailwind projects.

Don't install this package directly — use the Forkshop CLI:

    npx forkshop init

See [forkshop.dev](https://forkshop.dev) for documentation and examples.
