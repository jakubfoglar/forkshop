The `forkshop` CLI manages the scaffold layer Forkshop drops into
your project.

## `forkshop init`

Adds Forkshop to a Next.js project. Run once.

```bash
npx forkshop init
```

Behavior:

1. Preflights — requires `app/` (App Router) and a `@/*` path
   alias in `tsconfig.json`.
2. Aborts if `forkshop.json` already exists. Use `forkshop update`
   to refresh an existing install.
3. Fetches the registry manifest from `forkshop.dev/r/`.
4. Drops the scaffold layer (route stubs, skill files,
   `app/forkshop/CLAUDE.md`, Raveo font).
5. Appends `@import "@forkshop/engine/forkshop.css";` to your
   `globals.css` — idempotent. Warns if it can't find a globals.css.
6. Merges `@forkshop/engine` into `package.json` `dependencies`. **Does
   not run your package manager** — it prints the install command for
   you.
7. Optionally installs the Claude Code producer pack (see below).
8. Writes `forkshop.json`.

| Flag                     | Description                                                  |
|--------------------------|--------------------------------------------------------------|
| `--force`                | Overwrite existing files. Use after a half-finished install. |
| `--registry <url>`       | Use an alternate registry URL.                               |
| `--install-claude-pack`  | Drop `.claude/hooks/forkshop-post-tool-use.sh` and register it in `.claude/settings.json`. See [Live AI agents](/docs/live-ai-agents). |

After `init`, run your install command, then open Claude Code and
say "set up Forkshop" — the setup skill scaffolds your first Board
and wires `next.config.*` for the locator.

## `forkshop update`

Refreshes the scaffold against the manifest the manifest points at.

```bash
npx forkshop update
```

What it does:

- Compares every scaffolded file's checksum against the upstream
  manifest.
- Lists files that have drifted (in upstream, in your copy, or
  both).
- Prompts once for confirmation; on accept, overwrites with
  upstream.
- Offers to bump the `@forkshop/engine` pin in `package.json` if a
  newer engine is available.

| Flag               | Description                                |
|--------------------|--------------------------------------------|
| `--check`          | Dry-run. Exits non-zero if any file drifted. |
| `--force`          | Overwrite locally edited files without confirming. |
| `--registry <url>` | Use an alternate registry URL.             |

## `forkshop diff <path>`

Shows a unified diff between your local copy of one scaffolded file
and the upstream version.

```bash
npx forkshop diff app/forkshop/CLAUDE.md
```

| Flag               | Description                  |
|--------------------|------------------------------|
| `--registry <url>` | Use an alternate registry URL. |

## `forkshop add <bundle>`

Not available yet. Returns a "not yet released" message. Reserved
for future community bundles.

## `forkshop.json`

`init` writes this file at your project root. It records:

- The pinned `@forkshop/engine` version.
- A checksum of every file `init` dropped.
- The list of bundles installed (currently just `init`).
- A schema version.

Commit it. `update` reads it to figure out which files came from
where and to detect drift.
