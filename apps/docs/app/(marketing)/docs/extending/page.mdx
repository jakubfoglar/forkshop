---
title: Extending Forkshop
description: Custom Node kinds, custom Layouts, theming, and embedding.
---

The four shipped Layouts and three shipped NodeTypes cover the
common cases. Past that, Forkshop is a small set of React
primitives — you compose your own.

## Custom NodeType

A NodeType is a plain object satisfying the `NodeType<T>` interface.
No factory function — just type the object.

```tsx
import type { NodeType, BaseNode } from "@forkshop/engine"

interface EmailNode extends BaseNode {
  kind: "email"
  templatePath: string
}

export const emailNodeType: NodeType<EmailNode> = {
  id: "email",
  match: (node): node is EmailNode => node.kind === "email",
  render: ({ node }) => (
    <iframe
      src={`/email-preview/${node.templatePath}`}
      style={{ width: node.width, height: node.height }}
    />
  ),
}
```

Pass your NodeType into the engine's NodeType registry when
mounting `<ForkshopCanvas>` (see the user-side `app/forkshop/CLAUDE.md`
for the exact wiring — it's scaffolded by init). The built-ins
(`inlineReactNodeType`, `iframeRouteNodeType`,
`iframeComponentNodeType`) are good references.

`agentMatch` is optional. Add it when you want agent activity on a
particular file to highlight Nodes of your kind.

## Custom Layout

A Layout is a React component that arranges Nodes. Use `NodeView`
to render any Node — it dispatches to the matching NodeType.

```tsx
import { NodeView, type AnyNode } from "@forkshop/engine"

interface Props {
  before: AnyNode
  after: AnyNode
}

export function BeforeAfter({ before, after }: Props) {
  return (
    <div style={{ display: "flex", gap: 32 }}>
      <NodeView node={before} />
      <NodeView node={after} />
    </div>
  )
}
```

Then use it in a Board file under `app/forkshop/`. Layouts are just
React — no registration step.

## Theming

The engine ships color tokens as CSS variables in
`@forkshop/engine/forkshop.css`. Override any of them in your `:root`
— the engine's chrome picks them up at the next render, no rebuild.

```css
:root {
  --forkshop-canvas: #1a1a1a;
  --forkshop-fg: #e5e5e5;
  --forkshop-accent: #f97316;
}
```

The full set:

| Variable                      | Used for                                  |
|-------------------------------|-------------------------------------------|
| `--forkshop-canvas`           | Main canvas background.                   |
| `--forkshop-surface`          | Sidebar and panel backgrounds.            |
| `--forkshop-surface-2`        | Secondary surface (hover, inset).         |
| `--forkshop-fg`               | Foreground text.                          |
| `--forkshop-fg-muted`         | Secondary text.                           |
| `--forkshop-border`           | Default border.                           |
| `--forkshop-border-strong`    | Emphasized border.                        |
| `--forkshop-accent`           | Selection, focus, primary actions.        |
| `--forkshop-accent-fg`        | Text on accent.                           |
| `--forkshop-agent`            | Default agent activity color.             |
| `--forkshop-agent-fg`         | Text on agent.                            |

Spacing, radius, font-size, and font-weight tokens are Tailwind
utility scales — hardcoded in the engine's Tailwind preset, not
runtime-overridable.

## Embedding

`<ForkshopCanvas>` is a normal React component. Mount it in a page
of your own — a marketing demo, an internal dashboard, a portfolio
shot.

```tsx
import { ForkshopCanvas } from "@forkshop/engine"

<ForkshopCanvas
  fitMode="none"       // render at native 1:1 scale, no auto-fit
  initialZoom={0.75}   // optional starting zoom
  initialPan={{ x: 40, y: 40 }}
>
  {/* boards */}
</ForkshopCanvas>
```

`fitMode` accepts `"width"` (default), `"both"`, or `"none"`. Pass
`"none"` when the stage should render at its natural scale without
auto-fitting to the viewport. Each tile is a real iframe, so a
handful per page is fine and a gallery of twenty is too many. The
full mounting pattern (sidebar, node-type registry, board picker)
lives in your scaffolded `app/forkshop/page.tsx` — copy from there.
