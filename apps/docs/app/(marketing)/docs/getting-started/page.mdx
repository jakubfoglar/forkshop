---
title: Getting Started
description: Add Forkshop to an existing Next.js App Router project.
---

`npx forkshop init` scaffolds the file layer Forkshop needs into an
existing Next.js project and installs `@forkshop/engine` via your
package manager. After it finishes, open Claude Code and say "set up
Forkshop" — that's the only remaining step.

## Prerequisites

- A Next.js App Router project.
- `tsconfig.json` with a `@/*` path alias (the standard Next scaffold
  has this).
- A `globals.css` that gets imported from your root layout.

## Run init

From your project root:

```bash
npx forkshop init
```

What it does, in order:

1. Preflights — refuses to run if `app/` isn't found or `@/*` isn't
   in `tsconfig.json`.
2. Aborts if `forkshop.json` already exists. Re-running an install
   isn't the right command — see [CLI](/docs/cli) for `update` and
   `diff`.
3. Fetches the registry manifest from `forkshop.dev/r/`.
4. Drops the scaffold layer:
   - Route stubs in `app/api/forkshop/` (the dev-only edit API and
     the agent activity routes).
   - Skill files in `.claude/skills/forkshop-*.md` (read by Claude
     Code when you're working in the project).
   - `app/forkshop/CLAUDE.md` (the on-project agent reference).
   - The Raveo font in `public/fonts/forkshop/`.
5. Appends `@import "@forkshop/engine/forkshop.css";` to your
   `globals.css` if it isn't already there.
6. Writes `forkshop.json` — engine version, scaffold checksums,
   installed bundles.
7. Merges `@forkshop/engine` into your `package.json` `dependencies`
   and runs your detected package manager's install. Pass
   `--no-install` to skip this step.

## Finish the setup

Open Claude Code in the project and say **"set up Forkshop."** The
setup skill (dropped by init in step 4) scaffolds your first Board,
wires the locator loader into `next.config.*`, and detects your
existing primitives and routes. It's the part init deliberately
doesn't do.

Then start your dev server and open `/forkshop`.

## Opting in to the Claude Code activity hook

Pass `--install-claude-pack` to `init` (or set
`FORKSHOP_INSTALL_CLAUDE_PACK=1`) to also drop the post-tool-use
bash hook into `.claude/hooks/` and register it in
`.claude/settings.json`. The hook POSTs to your dev server when
Claude reads or edits files, so the canvas can highlight them. See
[Live AI agents](/docs/live-ai-agents) for what the activity looks
like.
